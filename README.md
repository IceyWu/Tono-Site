## 技术栈

- [Astro](https://astro.build/) — 静态站点生成
- GitHub Actions — 自动部署至 GitHub Pages

## 开发

```bash
pnpm install
pnpm dev        # http://localhost:4321
pnpm build      # 输出到 ./dist
pnpm preview    # 预览构建产物
```

## 部署

推送到 `main` 分支后自动通过 GitHub Actions 构建并部署到 GitHub Pages。
